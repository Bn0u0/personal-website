PROJECT / OVERVIEW

Not a demo world. A world that has to survive.

PicNest combines a living-world simulation with multiplayer persistence. Peeps can make their own decisions, the island can change through building and resource systems, and multiple players are expected to share one state without the simulation collapsing when a host disconnects or a save conflicts.

Core system

Peep behavior is driven by a decoupled FSM and score-based candidate system.

Engineering

The client uses React Three Fiber and Three.js with revisioned persistence and private realtime boundaries.

Reliability, onboarding, progression clarity and mobile performance remain explicit alpha workstreams.
